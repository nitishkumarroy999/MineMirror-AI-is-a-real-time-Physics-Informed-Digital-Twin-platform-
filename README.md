## How to Deploy on GitHub Pages

1. Create a new repository on GitHub named `minemirror-ai` (or any name you like).
2. Upload all files from this folder (keep the `assets` folder).
3. Go to **Settings → Pages**.
4. Under **Source** select branch `main` and folder `/ (root)`.
5. Click Save. After 1–2 minutes your site will be live.
